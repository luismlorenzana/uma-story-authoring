# Story authoring agent boundaries

Work on code and authorized normal story authoring. Keep actual stories, art, names, cast data, approvals,
prompts and generated packages under ignored content; commit only generic code/docs and invented fixtures.

## Owner-private art: mandatory for every AI agent

- Never view, open, render, describe, OCR, thumbnail, attach, scan, search, index or extract text/metadata from
  owner-private images, prompts, edit instructions, generation histories, actual approval records or related
  creative material. Never request private images, screenshots or prompts. Do not inspect the previous personal studio.
- This applies across repositories, local files, archives, caches, cloud storage, URLs and browser views.
  Exclude owner-private/, owner-only/, private-variants/, private-art-outbox/, art-private/ and any file containing
  .private. from every search, scan and review. Never browse a private outbox to learn its contents.
- Keep game private mode off during agent work. The normal story sandbox, art references, search and screenshots
  must use normal art only. Private alternatives must never enter a story pack, bible or normal publication.
- Opaque publishing is handled only by the documented count-only private-art commands in uma-art-authoring.
  They may machine-parse technical IDs/paths/checksums and transfer owner-approved files; agents may never inspect
  those files or dump their manifests. Never run the owner-only command on actual private inputs or approvals.
- Private prompts, notes and approvals stay owner-only on the Mac. Only selected output PNGs may enter the
  designated ignored outbox and separate art-private cloud feed. No private content in git, chats, logs or caches.
- Use invented bytes and approval records for tests. Never use real private images as fixtures or open private
  URLs to verify a publish. Check only the dedicated publisher's counters and ordinary storage object metadata.

These are agent conduct rules, not OS isolation or encryption. No owner unlock key is required. Read the Art
repository's docs/private-art-variants.md for the workflow. Normal authorized story work can continue as before.
